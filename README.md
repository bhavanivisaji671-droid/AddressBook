# Address Book Management System in C

## 📌 Project Overview

The Address Book Management System is a menu-driven C programming project used to manage contact information.

The application allows users to add, search, edit, delete, list, and save contacts.

## 🚀 Features

- Add a new contact
- Search for a contact
- Edit existing contact details
- Delete a contact
- List all contacts
- Save contact information
- Input validation for name, phone number, and email

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Linux / Ubuntu
- Visual Studio Code
